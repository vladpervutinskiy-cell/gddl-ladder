# GDDL Ladder

Мод для **Geometry Dash** (Geode), который берёт данные с [gdladder.com](https://gdladder.com) — GD Demon Ladder.

## Что делает

1. **Топ уровней.** Кнопка `GDDL TOP` в главном меню открывает список самых сложных уровней ладдера: место, название, автор и рейтинг (тир). Список листается по страницам, по клику на строку открывается страница уровня на сайте.
2. **Место уровня в топе.** Если открыть информацию об уровне сложности «демон» (10 звёзд, включая платформерных демонов), под счётчиком звёзд появляется кликабельная плашка вида `GDDL #839 (23.97)` — место уровня в общем топе ладдера и его рейтинг. Если уровень на GDDL не оценён — `GDDL not rated`.
3. **Кэш.** Ответы API кэшируются в памяти (место уровня — 5 минут, страницы топа — 2 минуты), чтобы не дёргать сайт при каждом открытии экрана.

## Как считается место

У GDDL нет готового эндпоинта «место уровня», поэтому место считается по рейтингу:

```
место = количество уровней с рейтингом строго выше + 1
```

Запрос: `GET /api/levels?minRating=<nextafter(rating)>&excludeUnrated=true&limit=1` → поле `total` = число уровней с рейтингом больше данного. `nextafter` — ближайшее представимое число больше рейтинга, чтобы фильтр `minRating` (он работает как `>=`) не захватил сам уровень.

Особенности API, которые учтены в коде:

* `minRating` с целыми числами ведёт себя странно (например, `minRating=39` возвращает и уровни с 38.667), поэтому всегда отправляются дробные значения с полной точностью.
* Максимальный `limit` — 25, сортировка по рейтингу: `sort=rating&sortDirection=desc`.
* Уровни с одинаковым рейтингом делят лучшее место (как в спорте): например, все уровни тира 39 имеют место 1.
* `GET /api/levels/{id}` возвращает `{}` для уровней без рейтинга.

Используемые эндпоинты (неофициальный API сайта):

* `GET https://gdladder.com/api/levels/{levelID}` — рейтинг уровня;
* `GET https://gdladder.com/api/levels?excludeUnrated=true&sort=rating&sortDirection=desc&limit=N&page=P` — страница топа.

## Настройки мода

| Настройка | По умолчанию | Описание |
|---|---|---|
| Rank badge on level info | вкл. | Плашка с местом на экране уровня |

| Levels per page | 10 | Сколько уровней на странице (5–12) |

## Сборка

Мод собран под **Geode 5.11.2** и **Geometry Dash 2.2081** (это зафиксировано в `mod.json`). Для другой версии Geode нужно поменять поле `"geode"` в `mod.json` и пересобрать.

Нужен [Geode SDK](https://docs.geode-sdk.org/getting-started/) и тулчейн:

* **Windows:** Visual Studio Build Tools (MSVC) + CMake + Ninja;
* **macOS:** Xcode Command Line Tools;
* **Android:** Android NDK (через `geode sdk install`).

Далее:

```powershell
# один раз: установить SDK нужной версии и CLI
geode sdk install 5.11.2

# в папке мода
geode build
```

Готовый `.geode` появится в `build/`. Его нужно положить в `<папка GD>/geode/mods/`.

### Сборка без локального тулчейна

В репозитории есть GitHub Actions workflow (`.github/workflows/build.yml`) — запушьте проект на GitHub, и сборка под все платформы запустится автоматически (Actions → Build Geode Mod → артефакт). В workflow уже указан SDK 5.11.2, чтобы сборка не уехала на другую версию Geode.

## Важно

* Мод **не собирался целиком**: на машине, где он создавался, нет MSVC/CMake/Geode CLI, поэтому .geode ещё не получен. Исходники прогнаны через `clang++ -std=c++23 -fsyntax-only` с реальными заголовками Geode 5.11.2 и сгенерированными биндингами GD 2.2081 (Windows-таргет) — ошибок нет, но первая настоящая сборка всё равно может выдать что-то новое (линковка, особенности MSVC).
* API у сайта неофициальный и может измениться. При ошибке сети плашка показывает `GDDL ?`, попап — сообщение с возможностью повторить запрос (клик по тексту внизу попапа).
* Мод не конфликтует с официальным [GDDL Integration](https://github.com/B1rtek/Geode-GDDLIntegration): его плашка «Tier N» остаётся, а наша строка с местом рисуется под ней.
* Текст в игре — на английском, потому что шрифты Geometry Dash не поддерживают кириллицу.
